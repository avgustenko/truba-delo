# Журнал изменений truba-delo

**Правило для всех, кто меняет репозиторий (люди и нейросети):** каждое изменение записывается сюда в том же коммите, где сделано. Новые записи — сверху. Время — по Екатеринбургу (UTC+5).

Как писать запись:

```markdown
## ГГГГ-ММ-ДД ЧЧ:ММ — Короткое название изменения

- **Кто:** какая нейросеть или человек
- **Зачем:** просьба владельца своими словами («…») или найденная ошибка
- **Что изменено:** по пунктам, как для человека, который не видел работы
- **Где:** файлы
```
